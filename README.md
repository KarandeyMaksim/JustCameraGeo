Flutter Camera & Geolocation Upload App
Приложение на Flutter для съемки фото с фронтальной камеры, добавления комментария и отправки вместе с текущей геолокацией на сервер через HTTP POST-запрос с использованием multipart/form-data.

Особенности
Инициализация фронтальной камеры (или первой доступной, если фронтальная отсутствует).

Запрос и получение разрешений на использование камеры и геолокации.

Съемка фото.

Получение текущих координат устройства (широта и долгота).

Ввод комментария пользователем.

Отправка фото, координат и комментария на сервер через multipart POST-запрос.

Обработка ошибок и вывод статуса отправки.

Используемые пакеты
camera — работа с камерой устройства

geolocator — получение геолокации и работа с разрешениями

http — отправка HTTP-запросов

path_provider — доступ к временной директории устройства

path — работа с путями файловой системы


Требования
Flutter SDK

Устройство или эмулятор с фронтальной камерой

Активированная служба геолокации и разрешения на использование геолокации и камеры
